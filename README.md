# 塔羅貓 (tarotcat) 🐱🔮

一個現代、精緻的個人塔羅牌占卜與分析 Web 應用。

## 🎯 核心功能
- **塔羅牌占卜**: 提供多種牌陣（如單牌占卜、時間之流三張牌陣等）。
- **牌意分析**: 提供卡牌解讀與深入分析。
- **貓咪主題**: 融合貓咪元素與神祕學風格的視覺設計。

## 🛠️ 技術棧
- **前端**: HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3
- **設計**: CSS Grid/Flexbox, HSL 配色系統, Sleek Dark Mode, 微互動動畫

## 🚀 快速開始
本專案為純前端應用，無需繁瑣的後端設定：
1. 複製此專案到本機。
2. 以瀏覽器直接開啟 `index.html`，或使用 VS Code Live Server 啟動。
